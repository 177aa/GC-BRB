# Fig. 2d classifier comparison

This folder contains the original code and saved test predictions for the five-classifier comparison.

`run_original_baselines.py` uses the definitions in `original_sources/`. The recorded parameters and software versions are in `plan.json`. `saved_test_predictions.zip` contains the test predictions for six tasks and five runs per task.

Rerunning training also requires the 30 `final_portable.mat` files and identity maps from the original model archive. These inputs are not included here. The source files are unchanged and retain historical paths.
