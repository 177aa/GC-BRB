## Note on Code Availability

This repository currently provides the source code for the conference version of our work,
**Soft Evidence Fusion (SEF)**, which has been accepted as a Regular Paper at **IEEE BIBM 2025**.

The extended framework, **Adaptive Calibrated Evidential Fusion (ACEF)**, is an extension
of SEF that further enhances the framework and experimental scope. The implementation of
ACEF will be released upon acceptance of the extended paper.

Main dependencies:  
pytorch==2.2.2+cu121  
torch-geometric==2.6.1  
`python main.py -g 0 -t --lr 0.001 --seed 2025`
